CELLCOUNT — 03 | EXPLICAÇÃO DO CÓDIGO-FONTE
===========================================

Se estiver começando, leia primeiro o guia 01. Depois acompanhe
contador.py, analises.py e app.py nesta ordem. No VS Code, use
Ctrl+F para buscar o método citado. Ao ler um trecho, anote o valor

1. contador.py | A imagem e os pontos de uma análise

1.1. Importações, classe e constantes

    from pathlib import Path
    from PIL import Image, ImageChops, ImageDraw, ImageOps

Path trabalha com caminhos no Windows e no Colab. Image decodifica a
imagem, ImageOps corrige a orientação, ImageDraw desenha sobre a imagem
em memória e ImageChops combina máscaras. A declaração
`class ContadorCelulas:` abre o corpo da classe.
ERROS_IMAGEM reúne os tipos de exceção que o navegador e o histórico
tratam. OSError cobre arquivo ilegível, ValueError cobre dados ou
formato inválidos e Image.DecompressionBombError sinaliza que a
quantidade de pixels supera o limite do Pillow.
O dicionário FORMATOS relaciona a extensão, com ponto inicial, ao formato
que o Pillow informa. LIMITE_PREVIA é o máximo em pixels de cada lado.
RAIO_MARCADOR, COR_MARCADOR e COR_CONTORNO definem estilo e tamanho.
Para mudar só o desenho, edite essas três constantes. Para adicionar um
formato, confirme a compatibilidade do Pillow e adicione a extensão com
o formato correspondente. A interface lê as extensões desse dicionário.

1.2. Criar o contador e a prévia em __init__

    self.caminho = Path(caminho)
    self.nome = self.caminho.name
    self.extensao = self.caminho.suffix.lower()
    self.marcacoes = []
    self.sugestoes = []

A entrada caminho é a localização do arquivo carregado ou da cópia da
imagem no histórico. Path possibilita obter o último trecho com `.name`,
e `.suffix` devolve a extensão. `.lower()` transforma PNG e png na mesma
forma para a comparação. Os valores passam a fazer parte do objeto por
meio de `self.`. `[]` cria listas novas para cada objeto, uma para as
marcações confirmadas e outra para as sugestões pendentes.

    imagem = self.abrir_imagem()
    self.largura, self.altura = imagem.size
    imagem.thumbnail((self.LIMITE_PREVIA, self.LIMITE_PREVIA))
    self.previa = imagem

abrir_imagem devolve um objeto Pillow orientado. A tupla `.size` tem dois
inteiros e é desempacotada em largura e altura antes de reduzir a imagem.
thumbnail recebe uma tupla com os dois limites e altera apenas a instância
Pillow em memória. Mantém a proporção e pode deixar a imagem no tamanho
original se ela já for pequena. A referência self.previa será copiada
para desenhar sobre ela. Para testar outra resolução de prévia, altere
LIMITE_PREVIA e compare o nome e a resolução exibidos em Contagem.

1.3. Validar, orientar e preparar em abrir_imagem

    with Image.open(self.caminho) as imagem:
        formato_esperado = self.FORMATOS.get(self.extensao)
        if formato_esperado is None or imagem.format != formato_esperado:
            raise ValueError("O conteúdo da imagem não corresponde à extensão do arquivo.")
        imagem = ImageOps.exif_transpose(imagem)

`with` fecha o arquivo quando termina o bloco, mesmo se ocorrer um erro.
`.get` devolve o formato associado à extensão ou None. `or` torna a
condição verdadeira se pelo menos um dos testes for verdadeiro. `!=`
compara o formato detectado com o esperado. `raise` interrompe o método
e sinaliza o problema a quem chamou. `exif_transpose` devolve uma imagem
em memória, aplicando rotações ou espelhamentos de orientação EXIF. O
código usa a primeira página em um TIFF com várias páginas.

    if imagem.mode.startswith("I") or imagem.mode == "F":
        imagem = imagem.convert("F")
        menor, maior = imagem.getextrema()

Os modos I e I;16 representam tons inteiros de alta profundidade. F é
o modo de ponto flutuante de Pillow. `.startswith("I")` cobre os modos
com esse prefixo. convert("F") cria uma imagem cujos tons podem ser
escalados em ponto flutuante. getextrema retorna os limites observados.
O teste `menor < maior and float("-inf") < menor and maior < float("inf")`
exige uma faixa positiva e finita antes de dividir pela diferença entre
máximo e mínimo. float("inf") representa infinito positivo.

    escala = 255 / (maior - menor)

    def ajustar_tom(pixel):
        return pixel * escala + (-menor * escala)

    imagem = imagem.point(ajustar_tom)

O ganho é calculado uma vez. A função interna usa as variáveis menor e
escala do método, e point aplica essa transformação linear aos tons. O
menor tom vira aproximadamente 0 e o maior, 255. `imagem.convert("L")`
converte para 8 bits em escala de cinza mesmo se a faixa fosse constante.
Essa transformação afeta a prévia e o PNG, enquanto o TIFF arquivado
conserva os seus valores originais. Mude essa conversão somente se você
souber qual faixa tonal quer mostrar nos seus arquivos.

    if "A" in imagem.getbands() or "transparency" in imagem.info:
        return imagem.convert("RGBA")
    return imagem.convert("RGB")

`in` procura a banda A (alfa) ou metadados de transparência. RGBA guarda
RGB mais a transparência. RGB guarda as três cores. A conversão permite
desenhar as mesmas cores em imagens que começaram em modos diferentes.
O método é chamado em __init__ para criar a prévia e ao exportar o PNG.

1.4. Converter pixels em coordenadas_originais

    if not (0 <= x < self.previa.width and 0 <= y < self.previa.height):
        raise ValueError("Clique dentro da imagem para marcar uma célula.")
    x_original = int((x + 0.5) * self.largura / self.previa.width)
    y_original = int((y + 0.5) * self.altura / self.previa.height)
    return x_original, y_original

As entradas X e Y estão em pixels da prévia. A comparação encadeada
`0 <= x < ...` inclui zero e exclui o primeiro pixel além da borda.
`and` exige que os dois eixos caibam na imagem. `not` inverte o resultado
para sinalizar o caso inválido. Some 0.5 para usar o centro do pixel e
multiplique pela razão entre original e prévia em cada eixo. int descarta
a parte fracionária de um número positivo, selecionando o pixel original
que contém o ponto. revisar_clique recebe a tupla antes de decidir
se um clique rejeita uma caixa ou adiciona uma célula.
Se mudar o tamanho da prévia, a relação se ajusta com `.width` e `.height`.

1.5. Registrar pontos em adicionar_celula

    if distancia_minima > 0:
        for x_anterior, y_anterior in self.marcacoes:
            dx = x - x_anterior
            dy = y - y_anterior
            if dx ** 2 + dy ** 2 < distancia_minima ** 2:
                return False

Recebe X, Y e o limite já na escala de pixels originais. for desempacota
cada ponto anterior. dx e dy são diferenças com sinal. `** 2` eleva ao
quadrado. Comparar os quadrados evita calcular a raiz da soma. Se a
distância for menor que o limite, return False encerra a operação antes
de incluir o ponto. Igualdade passa pela regra. Limite 0 pula a busca.
Para experimentar uma regra inclusiva, trocar `<` por `<=` passa a
bloquear também os pontos exatamente no limite quando ele é positivo.

    self.marcacoes.append((x, y))
    return True

• self é o objeto ContadorCelulas que recebeu a chamada.
• marcacoes é o atributo lista desse objeto. O ponto em self.marcacoes
  acessa o atributo. O segundo ponto acessa o método append da lista.
• x e y são os valores fornecidos pelos parâmetros deste método.
• A vírgula em (x, y) forma a tupla com uma coordenada em cada posição.
  Os parênteses internos agrupam a dupla. Os parênteses externos chamam
  append passando um único argumento, a tupla.
• append acrescenta a tupla no final da própria lista. A extensão da
  lista cresce em um e a nova marca é a primeira a sair com pop().
• return True informa ao chamador que a contagem precisa ser redesenhada.

revisar_clique recebe o ponto da prévia e converte para a imagem original.
Primeiro tenta rejeitar uma caixa de sugestão que contém o clique.
Em seguida, se a caixa não existir, tenta adicionar a célula. A saída
tem dois valores, o booleano mudou e a mensagem. Computador e celular
chamam o mesmo método para aplicar essas decisões.

1.6. Desfazer, limpar e calcular o total

    if self.marcacoes:
        self.marcacoes.pop()
        return True
    return False

desfazer_marcacao testa se a lista contém elementos antes de chamar pop().
pop() tira o último item e o devolve. Aqui, o método ignora o ponto que
saiu e devolve um booleano para a interface decidir se redesenha.
Em limpar_marcacoes, `self.marcacoes.clear()` e `self.sugestoes.clear()`
esvaziam as duas listas. O método termina implicitamente com None.
`return len(self.marcacoes)` em obter_total
usa a lista como única fonte de contagem. Depois de modificar a lista,
chame obter_total() para ler o total sem precisar somar ou subtrair à mão.

1.7. Detectar e revisar regiões de possíveis células

    tons = self.previa.convert("L")
    mascara = tons.point(tabela)

_criar_mascara usa a prévia limpa e converte suas cores para tons de
cinza de 0 a 255. `tabela = [0] * 256` prepara uma lista de zeros.
O for percorre `range(256)`. Para células claras, a condição aceita
`tom >= limiar`. Para escuras, aceita `tom <= limiar`. Quando uma
dessas combinações é verdadeira, `tabela[tom] = 255` troca o zero
pelo valor de um pixel ativo. point troca cada tom pelo valor de sua posição em
tabela. ImageChops.multiply combina essa máscara com a banda alfa
quando a imagem é RGBA. Os pixels transparentes viram zero.

Em detectar_celulas, getextrema devolve o menor e o maior valor da máscara. Se o maior for
zero, ela está vazia. Se o menor for positivo, todos os pixels estão
conectados e a região toca a borda. Nos dois casos o método devolve 0.
bytearray guarda os valores em uma sequência editável. enumerate entrega
o índice inicio e o valor ativo durante a busca. Um pixel diferente de
zero inicia a chamada a _medir_regiao. Esse método coloca esse pixel
em pilha, uma lista de trabalho.

    y, x = divmod(pilha.pop(), largura)
    area += 1
    soma_x += x
    soma_y += y

O quociente da divisão é a linha Y e o resto é a coluna X. O código
atualiza a área, a soma das coordenadas e os limites da caixa. Cada
vizinho ativo acima, abaixo, à esquerda ou à direita entra na pilha
com append. Quando um pixel entra, seu valor vira zero na lista para
evitar revisitas. A imagem e a prévia continuam intactas.

Exemplo de uma região em uma imagem de 6 × 5 pixels. Suponha que os
únicos pixels ativos sejam (2, 1), (3, 1), (2, 2) e (3, 2). Os índices
no bytearray são 8, 9, 14 e 15, pois o índice é Y vezes 6 mais X.
Começando por 8, o método encontra 9 e 14 ao examinar os vizinhos.
Ao final, mede área 4, caixa (2, 1, 3, 2) e centro (2.5, 1.5).
Se as duas resoluções coincidirem, coordenadas_originais devolve
(3, 2), porque soma 0.5 ao centro antes de converter para inteiros.

_medir_regiao devolve área, centro e caixa. O centro vem das médias
`soma_x / area` e `soma_y / area`. Depois de medir a região,
detectar_celulas pula caixas que tocam a borda.
Multiplica a quantidade de pixels da região pelo produto das razões
de largura e altura para estimar a área em pixels² da imagem original.
Aplica os limites fornecidos e coordenadas_originais converte o
centro. Cada item de sugestoes guarda `(ponto, caixa)`, com o ponto na
escala original e a caixa na escala da prévia. O retorno é a quantidade
de sugestões. Para estudar o efeito de vizinhos em diagonal, modifique
a lista de deslocamentos `dx, dy` e compare componentes isolados.

descartar_sugestao usa enumerate para achar a caixa do clique e remove
o item correspondente com pop(indice). incorporar_sugestoes percorre os
pontos, chama adicionar_celula para aplicar a mesma distância mínima
da contagem manual e retorna quantos entraram. Ao final, limpa as caixas.

1.8. Desenhar os marcadores

    if resolucao_original:
        imagem = self.abrir_imagem()
        proporcao = max(self.largura / self.previa.width, self.altura / self.previa.height)
    else:
        imagem = self.previa.copy()
        proporcao = 1

O parâmetro resolucao_original usa False por padrão. Para o PNG, abrir
o original permite renderizar nas dimensões completas. max escolhe a
maior relação de tamanho para ajustar o raio dos círculos. Para a prévia,
copy cria pixels independentes para preservar a base limpa. `round` dá
um raio inteiro e max(1, round(proporcao)) garante borda de ao menos um
pixel. `ImageDraw.Draw(imagem)` prepara o objeto que altera essa cópia.

    for x, y in self.marcacoes:
        cx = int((x + 0.5) * imagem.width / self.largura)
        cy = int((y + 0.5) * imagem.height / self.altura)

cx e cy são o centro do círculo na imagem de saída, que pode ser menor.
Se a imagem tem o tamanho original, a divisão recupera o próprio X e Y.
ellipse recebe uma caixa `(esquerda, topo, direita, base)` e desenha um
círculo quando altura e largura são iguais. `outline=...` escolhe a cor
da borda e `width=...` sua espessura. Primeiro vem o círculo escuro com
espessura dobrada. A segunda caixa é menor em borda pixels de cada lado
e recebe o anel ciano. A ausência de preenchimento mantém o centro
visível. `return imagem` devolve o resultado ao Gradio ou à exportação.
Para alterar o tamanho, ajuste RAIO_MARCADOR e confira se sobra centro.
Quando `mostrar_sugestoes=True` e a saída é uma prévia, `rectangle`
desenha as caixas roxas antes dos círculos. Exportação e histórico
usam o valor padrão False e mostram apenas marcações confirmadas.


2. analises.py | Histórico e exportação de dados

2.1. Preparar o armazenamento

csv e json leem ou escrevem formatos tabulares e estruturados. shutil
copia o arquivo, datetime produz e interpreta datas, Path organiza
caminhos e uuid4 gera identificadores independentes. A classe começa com:

    self.pasta = Path(pasta)
    self.pasta_imagens = self.pasta / "imagens"
    self.pasta_imagens.mkdir(parents=True, exist_ok=True)

`/` une segmentos de um Path. mkdir cria a pasta filha, `parents=True`
cria os pais necessários e `exist_ok=True` aceita uma pasta já existente.
O argumento pasta chega de app.py. Para testar sem mexer nas análises
reais, forneça outra pasta ao criar AplicacaoCellCount.

2.2. Montar o registro e publicá-lo em salvar_analise

    identificador = uuid4().hex
    arquivo_imagem = identificador + contador.extensao

uuid4() produz um identificador aleatório, `.hex` devolve seu texto sem
hífens e `+` acrescenta a extensão do arquivo. Assim duas imagens com o
mesmo nome podem ser salvas em registros diferentes. O dicionário
registro recebe id, amostra, imagem, arquivo_imagem, largura, altura,
total, data_hora, observacoes e marcacoes. `strip()` tira espaços nas
extremidades da amostra e observações. nome é o nome original mostrado,
e arquivo_imagem é o nome usado no disco. `contador.obter_total()` lê
a lista e `.copy()` faz uma cópia dos pontos. As tuplas não mudam, então
essa cópia de lista basta para o registro. `datetime.now().astimezone()`
obtém o horário do ambiente de execução com seu deslocamento de fuso.
`isoformat(timespec="seconds")` converte a data para um texto legível por
Python, incluindo segundos e fuso. Para adicionar uma informação, veja
o exercício de área no guia 07.

    shutil.copyfile(contador.caminho, imagem)
    with temporario.open("w", encoding="utf-8") as arquivo:
        json.dump(registro, arquivo, ensure_ascii=False, indent=2)
    temporario.replace(destino)

imagem, temporario e destino são caminhos distintos com o mesmo ID.
copyfile grava a cópia intacta. `.open("w", ...)` abre para escrita.
json.dump serializa o dicionário e converte tuplas em arrays JSON.
ensure_ascii=False preserva escrita direta de acentos. indent=2 formata
com recuo de dois espaços. O temporário tem extensão .tmp. replace muda
o nome para .json após fechar a escrita. O histórico procura apenas .json.
`try` envolve a escrita. `except OSError` trata falhas de arquivo. Cada
`unlink(missing_ok=True)` tenta remover o arquivo parcial e ignora sua
ausência. `raise` sozinho repassa o erro à interface. Em sucesso,
`return registro` entrega o dicionário para uso pelo chamador.

2.3. Listar, carregar e recuperar o caminho da imagem

    for caminho in self.pasta.glob("*.json"):
        registros.append(self.carregar_analise(caminho.stem))
    return sorted(registros, key=self.data_analise, reverse=True)

registros começa como lista vazia. glob filtra pela extensão. `.stem`
fornece o nome antes da extensão, usado como identificador. carregar_analise
verifica `identificador.isalnum()` antes de concatenar o nome com .json,
impedindo separadores de caminho no identificador. `.open` sem modo
explícito lê o arquivo. `json.load(arquivo)` devolve as estruturas
Python. data_analise transforma o texto de `registro["data_hora"]` com
datetime.fromisoformat. sorted cria uma lista ordenada usando esse
método como chave. `reverse=True` põe os recentes primeiro. Se quiser
inverter a ordem, ajuste reverse. caminho_imagem combina pasta_imagens
com `Path(registro["arquivo_imagem"]).name`, que seleciona o nome final
registrado para a cópia. Abrir o JSON funciona mesmo se essa cópia sumir.

2.4. Preparar textos e exportar

    if texto.lstrip().startswith(("=", "+", "-", "@")) or texto.startswith(("\t", "\r", "\n")):
        return "'" + texto
    return texto

lstrip tira espaços do início para a verificação. startswith recebe
uma tupla de prefixos e aceita qualquer um deles. `\t`, `\r` e `\n`
representam tabulação, retorno de carro e quebra de linha. Se o texto
puder ser lido como fórmula por uma planilha, texto_csv prefixa um
apóstrofo para abrir como texto. O JSON continua com o valor registrado.

    with destino.open("w", encoding="utf-8-sig", newline="") as arquivo:
        escritor = csv.writer(arquivo)

exportar_csv recebe um Path de saída e chama listar_analises para obter
os registros. utf-8-sig coloca um sinal de codificação no início para
facilitar a leitura de acentos em planilhas. newline="" deixa a biblioteca
csv controlar as quebras, inclusive no Windows. writerow grava primeiro
os nomes de CAMPOS_CSV. O laço `for campo in self.CAMPOS_CSV` lê
os valores na mesma ordem. texto_csv trata os campos de TEXTOS_CSV.
`json.dumps` transforma marcacoes em uma string JSON que ocupa uma
célula do CSV. Para mudar a ordem das colunas, edite CAMPOS_CSV.
app.py fornece o caminho e, após a escrita, oferece o arquivo para download.

2.5. Reconstituir a análise em rever_analise

    detalhes, foto = self.analises.rever_analise(registro)

As duas interfaces usam esse método. A entrada é o dicionário já
carregado por carregar_analise. As f-strings organizam ID, amostra,
arquivo, dimensões, data, total e observações. Cada \n inicia uma linha.
Quando as observações estão vazias, or escolhe "Sem observações".

O método tenta criar ContadorCelulas com o caminho da cópia original.
ERROS_IMAGEM cobre uma cópia ausente ou ilegível. Nesse caso, retorna
os detalhes com um aviso e None no lugar da foto. Se abrir, o método
coloca os pontos salvos em contador.marcacoes e chama desenhar_marcadores.
O resultado é uma tupla com texto e imagem pronta para a tela. A
contagem em andamento tem seu próprio objeto e continua independente.


3. app.py | Interface web e ligação com as regras

3.1. Importações, configuração e ponto de entrada

gradio recebe o apelido gr. Os imports locais trazem ContadorCelulas,
ERROS_IMAGEM e GerenciadorAnalises. Path monta caminhos. TemporaryDirectory
cria a área dos downloads e uuid4 fornece nomes únicos. os.environ e
sys.modules ajudam a reconhecer o Colab em executar.

    if __name__ == "__main__":
        AplicacaoCellCount().executar()

Quando você roda app.py, __name__ vale "__main__" e as duas chamadas
criam a aplicação e iniciam o servidor. Ao importar a classe, essa
condição fica falsa. __init__ aceita pasta_dados opcional. Quando é
None, __file__ indica o arquivo do programa. Path(...).resolve().parent
localiza sua pasta e / "dados" escolhe a pasta de armazenamento.
self.analises guarda o gerenciador, self.exportacoes guarda a pasta
temporária e self.interface recebe a tela criada em construir_interface.

Em executar, colab recebe True se o ambiente tiver COLAB_RELEASE_TAG
ou se google.colab estiver carregado. O Gradio recebe esse valor em
share e debug. O tema Soft aplica fontes e cores aos controles.
CSS é a string de estilo. #marca representa o cabeçalho, #imagem
define o fundo da prévia e o cursor, .painel define os cartões, .medidas organiza os
indicadores e #total realça a contagem ativa. gr.HTML recebe o código
do cabeçalho e dos indicadores. medida recebe um rótulo e um número
e monta um cartão com span e strong. aria-live permite anunciar
mudanças aos leitores de tela. Para ajustar as cores, edite CSS
ou as opções do tema. Para trocar texto, procure o rótulo do controle.

3.2. Construir a tela

    with gr.Blocks(title="CellCount", analytics_enabled=False) as tela:
        estado = gr.State()

with indica ao Gradio onde colocar os componentes. as tela dá um
nome ao objeto principal. gr.State guarda um contador por sessão e
começa com None. A linha abaixo reúne dois contextos. O Gradio cria
a linha dentro da aba.

    with gr.Tab("Contagem"), gr.Row():

• Contagem. A primeira coluna tem o arquivo, a resolução, a foto e os
  botões Desfazer e Limpar. gr.File usa as chaves de FORMATOS como
  extensões aceitas. gr.Image mostra a prévia PNG e oferece tela
  cheia. A segunda coluna tem o contador, a mensagem, os dados da
  amostra e a distância mínima. No Accordion, Checkbox escolhe
  células claras, Slider controla brilho e os dois Number recebem
  limites de área. Um botão gera o PNG e DownloadButton o disponibiliza.
• Histórico. Dataframe mostra uma linha por análise. headers fixa
  a ordem das colunas e datatype indica seus tipos. O Textbox à
  esquerda mostra os detalhes após a seleção. O Accordion guarda a
  tabela X e Y e a imagem volta a aparecer quando estiver disponível.
  O botão CSV gera um download com todos os registros.
• Resultados. Um gr.HTML recebe as três medidas juntas. Os cartões
  são calculados ao abrir a aba, carregar a tela ou salvar uma análise.

3.3. Ligar botões, entradas e saídas

    saidas = [estado, foto, total, status, png]
    arquivo.change(self.carregar_imagem, arquivo, saidas + [info, amostra, notas], **fila)

change chama carregar_imagem ao alterar o arquivo. O segundo argumento
é a entrada e o terceiro define os componentes que recebem o retorno.
Somar listas acrescenta três componentes à lista base. O retorno
deve ter a mesma ordem e o mesmo tamanho. **fila envia as opções
como argumentos nomeados. O concurrency_id compartilhado, com limite
1, deixa uma ação de cada vez editar a contagem. api_visibility
mantém essas ações vinculadas à interface.

foto.select chama marcar com estado e distancia. A anotação
evento: gr.SelectData faz o Gradio fornecer os dados do clique.
trigger_mode multiple permite enfileirar vários cliques e
show_progress hidden mantém a imagem visível durante a edição.
Os botões chamam seus métodos com .click. gr.on junta tela.load e
as duas seleções de aba para executar a mesma leitura. gravacao.success
dispara a leitura do histórico quando salvar termina com sucesso.
Os eventos de PNG e CSV recebem os arquivos gerados e os oferecem
nos respectivos botões de download.

3.4. O caminho de uma edição

atualizar_contagem recebe um contador e uma mensagem. Se existe
imagem, desenha os marcadores e as sugestões e lê o total. A tupla
retornada tem cinco posições. O contador volta para estado, a
imagem para foto, o HTML para total, a mensagem para status e
gr.update(value=None, visible=False) esconde o download anterior.
Ao retornar gr.skip(), exibir_mensagem preserva o componente
correspondente. Apenas o quarto valor é uma mensagem nova.

carregar_imagem inicia contador, info e mensagem com None,
texto vazio e a instrução de upload. O try cria ContadorCelulas.
except ERROS_IMAGEM trata a falha. O else descreve a imagem se
a abertura terminou normalmente. A saída inclui a resposta padrão
mais a resolução, o nome da amostra vazio e as observações vazias.

    x, y = evento.index
    mudou, mensagem = contador.revisar_clique(x, y, distancia)

O primeiro desempacotamento recebe as coordenadas da prévia.
O segundo recebe o booleano e a mensagem do núcleo. Em um clique
aceito ou numa caixa rejeitada, mudou vale True e a foto volta
redesenhada. Clique duplicado atualiza só status. TypeError e
ValueError são capturados para mostrar um aviso de coordenadas.

desfazer testa o booleano de desfazer_marcacao. limpar esvazia
marcações e sugestões. detectar verifica campos vazios e limites.
Área mínima começa em 1. Área máxima de 0 aceita qualquer área
acima do mínimo. Se for positiva, precisa ser pelo menos a mínima.
detectar_celulas devolve a quantidade de caixas para revisar.
incorporar guarda a quantidade pendente antes da edição, subtrai
as adicionadas e informa quantas a distância mínima ignorou.
descartar usa clear() somente na lista de sugestões.

3.5. Salvar, atualizar e consultar o histórico

salvar exige um contador e um nome com conteúdo. (amostra or "")
troca None por texto vazio e strip retira espaços das pontas.
As observações são opcionais. O método do gerenciador copia o
arquivo e grava o JSON. Se houver erro de disco, raise gr.Error(...)
from erro mostra uma mensagem e conserva a causa técnica.

    linhas.append([registro["amostra"], registro["imagem"], registro["total"], data, registro["id"]])
    total_salvo += registro["total"]

atualizar_historico percorre os registros guardados em disco.
append cria uma linha na mesma ordem dos headers. += soma as
células gravadas. O contador atual dá a primeira medida dos
resultados. Quando é None, a expressão condicional escolhe 0.
Os dois retornos são a lista de linhas e o HTML com os três cartões.
consultar_analise lê evento.row_value, valida se a linha contém o
ID na quinta coluna e chama rever_analise. Devolve texto, pontos
salvos e imagem. Para reordenar a tabela, atualize a lista dos
cabeçalhos, a linha e o índice usado para consultar.

3.6. Exportar

caminho_exportacao usa Path e uuid4 para criar uma subpasta por
download. exportar_imagem pede a renderização em resolução original
e salva imagem-anotada.png. Sugestões em revisão só aparecem na
prévia de contagem. exportar_csv grava resultados-cellcount.csv
usando o gerenciador. Os dois métodos passam caminho e visible=True
para o DownloadButton. A gravação em si ocorre antes dessa atualização.


4. Android | O caminho de um toque e a ponte Python

O guia 08 explica a instalação. O guia 09 explica as construções
de Java e as classes do Android. Para seguir uma ação pelo código,
abra TelaCellCount.java e procure pelo texto visível no botão.

4.1. Tela, gestos e fila

onCreate monta o cabeçalho, o menu de abas e as três áreas roláveis.
montarContagem organiza cartões para total, imagem, detecção e
registro. botao fornece aparência e recebe um Runnable com a ação.
campo cria o rótulo ligado ao EditText e determina o teclado.
abrirAba alterna a visibilidade das telas e atualiza a aba escolhida.

escolherImagem pede um arquivo ao Android. onActivityResult recebe
o URI selecionado. carregar copia os bytes para o cache, verifica
a extensão e chama a sessão Python por sessao().callAttr(...).
O seletor de exportação usa a mesma função de retorno, com códigos
distintos. executar inicia o trabalho no ExecutorService e devolve
um Runnable para atualizar as vistas na thread da interface.

ImagemAnalisavel guarda o retângulo que contém a imagem. ajustar
calcula a escala que permite ver a prévia inteira. aplicarZoom
muda tamanho e posição mantendo o foco do gesto. encaixar limita
o deslocamento para preservar o quadro útil. onDraw pinta a
prévia no retângulo. onSingleTapUp converte um toque dentro do
retângulo em X e Y da prévia, inclusive após zoom. Toque chama
TelaCellCount.marcar, que valida a distância e aciona editar.

4.2. SessaoCelular

__init__ guarda o gerenciador, o cache e o contador vazio. carregar
cria um contador para o arquivo temporário e mantém o nome original
de exibição. Quando troca a imagem, tenta remover a cópia temporária
anterior. Se a remoção falhar com OSError, pass permite continuar.
previa renderiza o PNG de trabalho e retorna o caminho. marcar usa

salvar chama o gerenciador. historico entrega à tela um texto JSON

temporária. O JSON devolvido inclui título, detalhes, caminho da

JSON com três números. exportar escolhe o desenho PNG original ou
o método de CSV. TelaCellCount lê esses JSONs e copia os arquivos
de exportação para o destino escolhido pelo usuário no Android.
