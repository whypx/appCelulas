CELLCOUNT — 01 | INTRODUÇÃO AO PYTHON
===================================

Abra contador.py e analises.py no VS Code. Os exemplos curtos a seguir
podem ser testados separadamente no terminal com python. Os trechos do
projeto indicam o método em que você pode procurá-los.

1. Variáveis e tipos de dados

Uma variável é um nome que se refere a um valor. Em Python, você cria o
nome com = e o próprio valor determina o seu tipo. A atribuição lê a
expressão à direita antes de guardar o resultado no nome à esquerda.

    total = 3
    distancia = 8.0
    marcado = True
    imagem = None

total é int (inteiro), distancia é float (número com parte decimal),
marcado é bool (True ou False) e None indica ausência de valor. Você
pode experimentar print(type(total)) e ver <class 'int'>.
Em app.py, atualizar_contagem começa com foto = None e total = 0.
Ao receber um contador, troca essas referências por uma imagem Pillow e
pelo total retornado pelo método obter_total.

2. Strings e números

Uma string (str) guarda texto entre aspas. O operador + pode juntar
strings ou somar números. F-strings começam com f e inserem valores
calculados entre chaves.

    nome = "Amostra A"
    total = 2 + 1
    mensagem = f"{nome} tem {total} células"

O resultado é "Amostra A tem 3 células". str.strip() tira espaços e
quebras de linha das extremidades. Em analises.py, amostra.strip() é
usado na gravação. Em app.py, carregar_imagem usa f-string para mostrar
nome, largura e altura. Em contador.py, dx ** 2 eleva dx ao quadrado,
/ calcula a divisão e int(...) descarta a parte fracionária.

3. Listas, tuplas e dicionários

A lista usa colchetes e mantém elementos em ordem. O primeiro índice
é 0. Você pode acrescentar, remover ou substituir seus elementos. A
tupla, aqui escrita com parênteses, agrupa valores numa ordem fixa. Um
dicionário organiza os dados em pares de chave e valor entre chaves.

    pontos = [(12, 9), (22, 15)]
    x, y = pontos[0]
    registro = {"amostra": "A", "total": len(pontos)}
    print(x, y, registro["total"])

A saída é 12 9 2. x, y = ... desempacota a dupla. len(...) devolve a
quantidade de elementos. CellCount usa uma lista de tuplas em
ContadorCelulas.marcacoes e dicionários em salvar_analise. JSON guarda
as duplas como arrays. Quando json.load lê o arquivo, cada dupla vem
como lista, e `for x, y in ...` funciona da mesma forma.

4. Condicionais if e else

if avalia uma condição. O bloco abaixo dele, com recuo, é executado
quando a condição é verdadeira. else executa o outro bloco. : termina
a linha da condição. == compara igualdade, > e < comparam ordem.

    distancia = 0
    if distancia > 0:
        print("Verificar distância")
    else:
        print("Aceitar o ponto")

O exemplo imprime "Aceitar o ponto". adicionar_celula usa if
distancia_minima > 0 para decidir se precisa percorrer a lista.
desenhar_marcadores usa if resolucao_original e else para escolher
entre abrir o arquivo completo ou copiar a prévia. `if self.marcacoes`
é verdadeiro quando a lista tem pelo menos um elemento.

5. Laço for

for ... in ... percorre uma coleção. Para cada elemento, Python
atribui seu valor à variável do laço e executa o bloco indentado.

    pontos = [(12, 9), (22, 15)]
    for x, y in pontos:
        print(x, y)

Cada iteração imprime uma dupla. Em desenhar_marcadores, o for repete
o desenho para cada dupla. Em atualizar_historico, o for lê o total
de cada registro e o soma ao total acumulado com +=.

6. Funções com def, parâmetros e argumentos

def define uma função. Os nomes nos parênteses da definição são os
parâmetros. Na chamada, os valores fornecidos são argumentos. Um
parâmetro com = pode ter um valor padrão.

    def legenda(nome, total=0):
        return f"{nome} · {total} células"

    texto = legenda("Amostra A", total=3)

"Amostra A" é um argumento posicional e total=3 é um argumento pelo
nome. Sem este argumento, total receberia 0. Em contador.py,
desenhar_marcadores(self, resolucao_original=False) usa a prévia por
padrão. exportar_imagem chama o método com resolucao_original=True.

7. return

return encerra a função e entrega um resultado ao chamador. Uma
função que chega ao fim sem return devolve None. Valores separados por
vírgula num return formam uma tupla que pode ser desempacotada.

    def posicao():
        return 40, 25

    x, y = posicao()

Em coordenadas_originais, a função devolve o par convertido. Em
adicionar_celula, um return False dentro do laço encerra o método e
impede a execução de append quando há uma marcação próxima.

8. import e bibliotecas

Uma biblioteca fornece código pronto para uma tarefa. import traz um
módulo para o arquivo. `as` escolhe um apelido e `from ... import ...`
traz um nome específico.

    import json
    import gradio as gr
    from pathlib import Path

    print(json.dumps([(12, 9)]))
    print(Path("dados") / "imagens")

Os resultados são o texto [[12, 9]] e um caminho com o separador do
sistema. json, csv, pathlib, datetime, shutil, uuid, os, sys e tempfile já
acompanham Python. Instale Gradio e Pillow com requirements.txt.
Gradio cria a interface e conecta eventos. Pillow, importado como
PIL, abre imagens e desenha círculos. app.py também importa as classes
dos módulos locais contador.py e analises.py.

9. append(), pop() e clear()

São métodos de listas e modificam a própria lista. append acrescenta
um item, pop() remove e devolve o último, clear esvazia a lista.

    pontos = []
    pontos.append((12, 9))
    pontos.append((22, 15))
    removido = pontos.pop()
    pontos.clear()

removido vale (22, 15) e pontos passa a ser []. Em contador.py, as
mesmas operações atendem marcar, desfazer e limpar. Teste se a lista
contém elementos antes de usar pop() para evitar IndexError. append e
clear devolvem None, então chame pontos.append(...) sem atribuir o
resultado de volta a pontos.
