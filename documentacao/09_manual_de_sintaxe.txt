2. NOMES, VALORES E OPERAÇÕES EM PYTHON

2.1. Código, linhas e blocos

Python executa instruções em ordem. Espaços no início da linha, chamados
de indentação, indicam que a instrução pertence a um bloco. Use quatro
espaços por nível. Nos exemplos abaixo, as linhas dentro do if ficam
mais à direita. O dois-pontos abre o bloco.

    total = 2
    if total > 0:
        print("Já há uma contagem.")
    print("Fim do exemplo.")

print(...) é uma função que mostra um valor no terminal. Funções usam
parênteses para receber informações. Parênteses também podem agrupar
expressões, como (x + 0.5) no cálculo de coordenadas, ou permitir que
uma expressão ocupe várias linhas. Nas listas, tuplas, dicionários e
chamadas de função, uma vírgula após o último item é válida e facilita
editar listas longas.

2.2. Atribuir e ler valores

    area = 0
    area += 1
    area = area + 1

O sinal = coloca o valor calculado à direita no nome à esquerda. +=
atualiza um nome somando um valor ao que já estava lá. Acima, area
termina em 2. Em _medir_regiao, area sobe um para cada pixel visitado.
Em self.previa = imagem, o ponto faz a atribuição a um atributo do
objeto. class e self serão explicados na seção 5.

Nomes como area_minima têm letras e sublinhados. Costuma-se usar letras
maiúsculas em valores de configuração, como LIMITE_PREVIA. Isso sinaliza
uma convenção de leitura. Python permite alterar esses valores.

2.3. Tipos e conversões

• int representa inteiros, como 1400 ou -1. Use int(2.9) para obter 2.
  Em coordenadas_originais, isso seleciona um índice inteiro de pixel.
• float representa valores com parte fracionária, como 0.5. Python usa
  ponto decimal no código. float("inf") representa infinito positivo e
  float("-inf") representa o negativo. abrir_imagem confere se os tons
  de uma imagem de alta profundidade estão dentro desses extremos.
• str representa texto. str(destino) converte um Path em texto para que
  a interface receba o caminho do arquivo.
• bool tem os valores True e False. A comparação 8 > 0 devolve True.
  Em detectar_celulas, claras decide qual grupo de tons será selecionado.
• None representa ausência de valor. O contador de uma sessão começa
  vazio e é substituído quando uma imagem válida é carregada.

    print(type(8), type(0.5), type("Amostra"), type(True))

type(...) mostra o tipo. O tipo define as operações disponíveis. Com
números 2 + 3 soma. Com textos "2" + "3" junta e produz "23".

2.4. Texto, aspas e montagem de mensagens

    nome = "Amostra A"
    total = 3
    mensagem = f"{nome} tem {total} células."
    print(mensagem)

Aspas simples e duplas criam textos. O f antes da primeira aspa faz da
string uma f-string. As chaves pedem ao Python que calcule e insira os
valores. Na expressão f"{registro['total']}", as aspas externas são
duplas e as da chave do dicionário são simples. Isso evita encerrar o
texto antes da hora. \n quebra a linha, \t insere uma tabulação e \r
representa retorno de carro. Você verá esses escapes nas mensagens do
histórico e na proteção dos campos CSV.

• .strip() tira espaços das extremidades. .lstrip() tira apenas os do
  início. Use em textos digitados pelo usuário.
• .lower() retorna o texto em minúsculas. A extensão .PNG passa a .png.
• .startswith(...) testa o começo do texto. Uma tupla de prefixos
  permite que qualquer um deles satisfaça o teste.
• .isalnum() testa se o texto tem apenas letras e números e se é
  preenchido. carregar_analise usa isso no nome do registro.
• "\n".join(pontos) junta textos com uma quebra de linha entre eles.
  A tela Android usa o resultado para mostrar as coordenadas.

Em app.py, CSS é um texto que ocupa várias linhas, delimitado por três
aspas. Textos literais vizinhos dentro de parênteses podem se juntar
sem usar +. indicador combina um fragmento HTML fixo com uma f-string.

2.5. Contas, comparações e condições

Use + e - para somar e subtrair, * para multiplicar, / para dividir e
** para potência. Em adicionar_celula, dx ** 2 significa o quadrado
da diferença entre as coordenadas X de dois pontos. dx ** 2 + dy ** 2
é o quadrado da distância entre eles. Dessa forma, o método pode
comparar a distância sem calcular a raiz quadrada.

Compare com ==, !=, <, <=, > e >=. O código 0 <= x < largura testa os
dois limites. O último X válido é largura - 1, pois o primeiro índice
é 0. Use is None para verificar se um valor está ausente e is not None
para verificar se existe. = serve para atribuir, enquanto == compara.

and exige as duas condições. or aceita pelo menos uma. not inverte
o resultado. No exemplo abaixo, or escolhe um texto alternativo.

    notas = ""
    print(notas or "Sem observações")

String vazia, lista vazia, zero e None são falsos quando avaliados em
if. No contador, if self.marcacoes verifica se existe pelo menos um
ponto antes de chamar pop(). if inicia uma decisão, elif testa outra
possibilidade e else cobre o caso restante.

    campo = "marcacoes"
    if campo == "amostra":
        print("Texto da amostra")
    elif campo == "marcacoes":
        print("Lista de pontos")
    else:
        print("Outro campo")


3. COMO O PROJETO AGRUPA INFORMAÇÕES

3.1. Listas

Colchetes criam uma lista. Os itens têm ordem e podem mudar.

    pontos = []
    pontos.append((10, 20))
    pontos.append((30, 50))
    print(pontos[0])
    removido = pontos.pop()
    copia = pontos.copy()
    pontos.clear()
    print(removido, copia, pontos)

append(item) acrescenta no fim. pop() retira o último item e o devolve,
enquanto pop(indice) escolhe a posição. clear() esvazia a própria
lista. copy() cria outra lista, preservando os itens que existiam
naquela hora. len(pontos) conta os itens. Em Python, pontos[-1] lê
o último quando a lista é preenchida. A contagem usa uma lista para
as marcações confirmadas e outra para sugestões pendentes.

3.2. Tuplas e desempacotamento

    ponto = (15, 22)
    x, y = ponto

A vírgula separa os dois elementos. A tupla organiza o par, e a
atribuição a x, y separa os valores. Uma tupla mantém o conjunto de
itens com que foi criada. A notação ponto[0] também lê X. Em
_medir_regiao, a saída area, centro, caixa reúne um número e duas
tuplas. Em detectar_celulas, os três nomes recebem essas informações
na mesma ordem. A lista sugestoes guarda pares (ponto, caixa).

A expressão (OSError, ValueError) cria uma tupla de tipos de erro.
Já ("", "", "") contém três textos vazios. Ao somar essa tupla às
saídas de carregar_imagem, o código acrescenta três valores para os
campos de nome do arquivo, amostra e observações.

3.3. Dicionários e teste de presença

    registro = {"amostra": "A", "total": 2}
    print(registro["total"])
    print(registro.get("observacoes", "Sem observações"))

Cada par tem a chave, dois-pontos e o valor, nessa ordem. Usar
colchetes com uma chave ausente gera KeyError. .get(chave, padrao)
permite fornecer um valor alternativo. O método FORMATOS.get(...)
devolve None se a extensão não estiver no dicionário e o padrão
for omitido.

in verifica se algo pertence a uma coleção. Em campo in TEXTOS_CSV,
procura o nome da coluna em uma tupla. Em "transparency" in imagem.info,
procura uma chave no dicionário de informações da imagem. Em
"COLAB_RELEASE_TAG" in os.environ, procura uma variável no ambiente.
O operador not in expressa a condição inversa quando necessário.


4. REPETIR INSTRUÇÕES E PERCORRER DADOS

    for x, y in [(10, 20), (30, 50)]:
        print(x, y)

for executa o bloco uma vez por item. O par é desempacotado em cada
rodada. range(256) fornece os inteiros de 0 a 255, usados para
montar a tabela de brilho. enumerate(pixels) fornece pares com o
índice e o valor. Isso permite iniciar a medição em cada pixel ativo.

while pilha executa enquanto houver elementos na lista pilha. Chamar
pop() retira o próximo pixel de trabalho. divmod(indice, largura)
devolve quociente e resto. Em _medir_regiao, o quociente representa
Y e o resto representa X. min(...) e max(...) produzem os menores e
maiores valores, usados para expandir os limites da caixa. continue
pula para a próxima rodada do for, como ao rejeitar uma região de
borda ou menor que a área mínima.

Trechos como for _, caixa e _, mensagem usam _ para avisar que aquele
valor lido não será utilizado. É um nome comum de variável. A
expressão abaixo produz os totais um de cada vez para sum(...).

    sum(r["total"] for r in registros)

Essa construção é uma expressão geradora. Ela aparece em
SessaoCelular.resultados. Para entender a conta, imagine iniciar um
total em 0 e somar r["total"] a cada volta do for.

bytearray(mascara.tobytes()) copia os pixels para uma sequência de
inteiros editável. O núcleo marca como zero o pixel já colocado na
pilha. Os dados editáveis pertencem a essa sequência de trabalho.
A prévia continua disponível para desenhar.


5. FUNÇÕES, CLASSES E TRATAMENTO DE ERROS

5.1. Definir e chamar funções

    def formatar(nome, total=0):
        return f"{nome} · {total} células"

    print(formatar("Amostra A"))
    print(formatar("Amostra A", total=3))

def apresenta o nome e os parâmetros. O argumento "Amostra A" ocupa
a primeira posição. total=3 escolhe pelo nome. Quando o argumento
é omitido, o padrão é 0. return encerra a chamada e entrega um
resultado. Se o método chegar ao fim sem return, devolve None.

Em contador.py, desenhar_marcadores usa dois padrões False. Ao chamar
desenhar_marcadores(resolucao_original=True), só a opção nomeada
muda. A função ajustar_tom, definida dentro de abrir_imagem, lê
menor e escala calculados pela função que a contém. O programa
entrega a função pelo nome a imagem.point para o Pillow usar.

Escrever self.salvar passa o método como referência. Escrever
self.salvar(...) executa o método e produz seu retorno. No Gradio, um botão recebe a
referência e executa o método mais tarde. Em sorted(registros,
key=self.data_analise, reverse=True), sorted chama a função key de
cada registro para comparar datas. reverse=True ordena do mais
recente para o mais antigo.

No trecho abaixo, **fila faz o Python tirar as chaves e os valores de
um dicionário e passá-los como argumentos nomeados.

    salvar.click(self.salvar, [estado, amostra, observacoes], status, **fila)

5.2. Classe, objeto, atributo e método

    class ContagemDeEstudo:
        def __init__(self):
            self.pontos = []

        def adicionar(self, x, y):
            self.pontos.append((x, y))

    contagem = ContagemDeEstudo()
    contagem.adicionar(10, 20)
    print(contagem.pontos)

class declara um modelo de objeto. Chamar ContagemDeEstudo() cria
uma instância. Python chama __init__ para colocar os dados iniciais
nela. self representa o objeto que recebeu a chamada. Python
preenche self quando você escreve contagem.adicionar(10, 20).
Um atributo guarda dados, como pontos. Um método executa uma
operação, como adicionar. Criar a lista dentro de __init__ dá a
cada instância sua própria lista.

Em ContadorCelulas, self.marcacoes pertence à imagem atual. Já
LIMITE_PREVIA fica declarado no corpo da classe e funciona como
configuração compartilhada. O sublinhado inicial de _criar_mascara
e _medir_regiao indica intenção de uso interno. Para disparar uma
análise da tela, chame detectar_celulas. Para alterar a forma de
medir a área, procure _medir_regiao.

5.3. Recursos, exceções e anotação de tipo

    with caminho.open(encoding="utf-8") as arquivo:
        registro = json.load(arquivo)

with abre um contexto. O arquivo é fechado ao sair do bloco, também
quando ocorre um erro. as dá um nome ao arquivo aberto. O projeto
também usa with Image.open(...) e with gr.Blocks(...).

try tenta executar um trecho. except trata os tipos de erro
indicados. except OSError as erro guarda a exceção em erro para
inspeção ou encadeamento. raise ValueError("...") sinaliza dados
inválidos. raise sozinho repassa a exceção já capturada. raise
gr.Error("...") from erro conserva a causa original e envia uma
mensagem clara ao navegador. pass deixa o bloco sem executar ação.
SessaoCelular usa essa forma quando uma cópia temporária antiga
não pode ser removida e a nova imagem já está disponível.

Tipos de erro usados no projeto

• OSError cobre falhas de abertura, escrita e cópia de arquivos.
• ValueError sinaliza formato, data ou coordenadas inválidas.
• TypeError pode surgir ao tentar calcular com um valor de tipo
  incompatível. KeyError indica chave ausente em um registro.
• Image.DecompressionBombError é um erro do Pillow quando a imagem
  supera o limite interno de segurança para quantidade de pixels.
• gr.Error é usado para relatar a falha na interface do navegador.

Em def marcar_celula(self, contador, distancia, evento: gr.SelectData),
os dois-pontos após evento introduzem uma anotação de tipo. Gradio
usa a anotação para fornecer os dados do clique. Ela é diferente
dos dois-pontos que iniciam o corpo de uma função.

Por fim, __file__ aponta para o arquivo Python em execução ou
importado. __name__ vale "__main__" quando você executa app.py
diretamente. Por isso o bloco final inicia o servidor só nessa
forma de execução. Importar AplicacaoCellCount permite que o Colab
ou outra parte do código escolha quando iniciar a tela.


6. IMPORTAÇÕES E BIBLIOTECAS

Uma biblioteca contém código pronto. Um módulo costuma ser um
arquivo importável. import json disponibiliza o nome json. A forma
import gradio as gr cria o apelido gr. from pathlib import Path importa
Path diretamente. from contador import ContadorCelulas importa
uma classe do arquivo contador.py do próprio CellCount.

6.1. Biblioteca padrão que acompanha Python

pathlib / Path
    Path(caminho) representa um caminho em vez de depender de barras
    escritas à mão. pasta / "imagens" junta duas partes do caminho.
    .name dá o nome final, .suffix a extensão, .stem o nome sem a
    extensão e .parent a pasta acima. .resolve() obtém o caminho
    absoluto. .mkdir(parents=True, exist_ok=True) cria as pastas
    necessárias e aceita uma pasta que já existe. .glob("*.json")
    busca os registros. .open(...) lê ou grava arquivos.
    .replace(...) move o arquivo temporário para o nome definitivo.
    .unlink(missing_ok=True) apaga um arquivo e tolera sua ausência.

json
    Converte dados em texto estruturado. json.dump(dados, arquivo)
    escreve diretamente. json.load(arquivo) lê de volta. dumps(dados)
    devolve uma string, útil no campo de coordenadas do CSV e na ponte
    com o Android. ensure_ascii=False mantém os acentos legíveis e
    indent=2 organiza o arquivo salvo. Uma tupla Python escrita em
    JSON é lida depois como lista. Ambas aceitam for x, y in pontos.

csv
    csv.writer(arquivo) cria um escritor de planilha em texto.
    escritor.writerow(...) grava uma linha, colocando aspas quando
    existem vírgulas, aspas ou quebras internas em um campo. Abra
    com newline="" para deixar a biblioteca controlar as quebras.
    encoding="utf-8-sig" ajuda planilhas a identificar os acentos.

shutil
    shutil.copyfile(origem, destino) copia os bytes do arquivo. Ao
    salvar uma análise, o original vai para dados/imagens antes da
    gravação do JSON. Isso permite revisar a imagem depois.

datetime
    datetime.now() obtém data e hora do sistema. .astimezone() inclui
    o fuso local. .isoformat(timespec="seconds") gera o texto armazenado.
    datetime.fromisoformat(...) recupera um objeto de data. strftime
    formata a exibição. %d, %m e %Y são dia, mês e ano. %H, %M e %S
    representam hora, minuto e segundo. %z é o deslocamento de fuso.

uuid
    uuid4().hex cria um identificador usado como nome único do
    registro ou de uma subpasta de exportação.

tempfile
    TemporaryDirectory(prefix="cellcount-") cria a pasta usada pelas
    exportações no computador. .name dá o caminho. Uma subpasta
    distinta para cada arquivo evita que dois downloads se sobrescrevam.

os e sys
    os.environ é um mapeamento de variáveis do ambiente. sys.modules
    lista módulos já carregados. app.py verifica sinais do Google
    Colab antes de iniciar o modo apropriado do Gradio.

6.2. Pillow — imagens, cores e desenho

O pacote instalado se chama Pillow e é importado pelo nome PIL.

• Image.open abre o formato de imagem identificado pelo conteúdo.
  .format informa esse formato. O CellCount compara o valor com a
  extensão esperada. .size dá (largura, altura), .width e .height
  leem cada dimensão, e .mode descreve o tipo de pixel.
• ImageOps.exif_transpose usa a orientação registrada na foto. Em
  TIFF com várias páginas, o projeto trabalha com a primeira.
• .convert("L") cria tons de cinza de 8 bits. "F" usa número com
  parte fracionária. "RGB" usa vermelho, verde e azul. "RGBA"
  acrescenta a transparência. .getbands() lista os canais e
  .getchannel("A") devolve o canal alfa. info guarda metadados.
• .getextrema() devolve os limites dos valores de um canal. .point(...)
  aplica uma função de tons ou uma tabela que substitui cada tom.
  Em imagens de alta profundidade, o projeto ajusta a faixa para
  o intervalo visível. Para detecção, point cria uma máscara.
• ImageChops.multiply combina a máscara com o canal de transparência.
  Pixels com alfa zero ficam fora da busca de regiões.
• .thumbnail((largura, altura)) reduz a imagem em memória, respeitando
  a proporção e os limites. .copy() cria uma imagem separada para
  desenhar. .tobytes() dá os valores dos pixels em bytes.
• ImageDraw.Draw(imagem) cria um desenhador. ellipse recebe o
  retângulo que delimita o círculo. rectangle desenha a caixa
  laranja. outline é a cor da borda e width determina sua espessura.
  O centro do círculo fica visível porque o código só desenha bordas.
• .save(destino) usa a extensão do arquivo para escolher o formato.
  A prévia do Android usa compress_level=1 no PNG para reduzir o
  tempo de processamento.

Este exemplo gera uma imagem para praticar.

    from PIL import Image
    foto = Image.new("RGB", (100, 80), "white")
    print(foto.size)
    print(foto.convert("L").getextrema())

Image.new é usado aqui para montar uma imagem de exercício. O
programa real abre a imagem que você selecionar.

6.3. Gradio — tela e eventos do navegador

Em AplicacaoCellCount.construir_interface, gr.Blocks organiza a tela.
gr.Tab cria abas, gr.Row dispõe itens lado a lado, gr.Column organiza
itens em coluna e gr.Accordion abre ou fecha um grupo de controles.
Estes componentes aparecem dentro de blocos with.

• gr.File recebe o caminho da imagem. gr.Image mostra a prévia e
  envia um evento de seleção. type="pil" usa objetos Pillow.
• gr.Textbox recebe ou apresenta texto. interactive=False deixa
  o campo somente para leitura. gr.Radio permite uma escolha.
  gr.Slider é um controle deslizante e gr.Number aceita números.
• gr.Button dispara ações. gr.DownloadButton recebe o caminho
  de um arquivo pronto para o usuário baixar.
• gr.Dataframe mostra linhas e colunas de dados. gr.HTML exibe
  indicadores e o cabeçalho. gr.Markdown monta títulos e instruções.
• gr.State mantém o contador de cada sessão. Cada sessão começa
  sem imagem e passa a guardar um ContadorCelulas após o upload.

.click, .change e .select ligam métodos a ações. Forneça a função,
as entradas e as saídas. A ordem das saídas precisa corresponder
à ordem dos valores devolvidos. evento.index traz as coordenadas
da imagem. evento.row_value traz a linha clicada no histórico.
.success dispara a leitura do histórico após salvar com sucesso.
gr.on liga a mesma ação ao carregamento inicial e à seleção de abas.

gr.skip() preserva um componente. gr.update(value=..., visible=...)
altera valor e visibilidade. Em cliques muito próximos, sem_edicao
atualiza apenas a mensagem, preservando a imagem. A configuração
de fila executa uma edição por vez. trigger_mode="multiple" permite
que cliques sucessivos sejam encaminhados. gr.themes.Soft(...).set(...)
seleciona as cores e o tema. .launch(...) inicia a aplicação.
Veja também o guia 04 para os exemplos completos dos eventos.


7. ACOMPANHE UM CLIQUE DO COMEÇO AO FIM

1) A interface abre a imagem e cria um ContadorCelulas. __init__
   registra a resolução original e guarda uma prévia de até
   LIMITE_PREVIA pixels em cada lado.
2) No navegador, marcar_celula recebe evento.index. Antes de usar a
   dupla, isinstance(evento.index, (list, tuple)) verifica o tipo e
   len(...) != 2 rejeita um valor com outra quantidade de elementos.
   No Android, ImagemAnalisavel calcula a dupla na prévia e a envia
   por SessaoCelular.marcar. Os dois chamam revisar_clique.
3) coordenadas_originais valida os limites e converte para o
   tamanho original. Se a largura original for 2800 e a prévia
   tiver 1400, o X 300 vira int((300 + 0.5) * 2800 / 1400), ou 601.
   Some 0.5 para usar o centro do pixel da prévia e calcule Y com
   as alturas correspondentes.
4) descartar_sugestao verifica primeiro se o clique cai dentro
   de uma caixa laranja. Se houver, remove a caixa. Nos demais
   casos, adicionar_celula testa a distância nas coordenadas
   originais e faz self.marcacoes.append((x, y)) se puder confirmar.

Leia a linha com append da esquerda para a direita. self é o
contador que recebeu a chamada. marcacoes é a lista dele. append
acrescenta um item. Os parênteses externos chamam append. Os
internos agrupam X e Y, formando um só item com dois elementos.

revisar_clique devolve o par (mudou, mensagem). mudou indica se
algum ponto ou caixa mudou. Se um clique rejeitou uma caixa,
mudou vale True e o total de células permanece igual. Se ficou
perto demais de uma marca, mudou vale False. O Gradio usa essa
informação para reaproveitar a prévia quando ela não precisa mudar.

No redesenho, obter_total usa len(self.marcacoes). desenhar_marcadores
converte cada posição para o tamanho da imagem de saída. Os círculos
vazados são desenhados em uma cópia da prévia ou numa nova leitura
do original, conforme o destino.


8. ENTENDA A DETECÇÃO, O HISTÓRICO E AS EXPORTAÇÕES

8.1. Da imagem até uma caixa laranja

_criar_mascara percorre os 256 tons. Uma comparação decide se o tom
recebe 255 (ativo) ou 0 (inativo). Por exemplo, para células escuras
com limiar 128, um tom 70 fica ativo e um tom 180 fica inativo.
Ao aplicar a tabela, o Pillow transforma todos os pixels de uma
vez. O código exclui os pixels transparentes do arquivo, quando houver.

_medir_regiao recebe o índice de um pixel ativo. Mede o grupo que
pode ser percorrido pelos vizinhos de cima, de baixo e dos lados.
Diagonais sozinhas deixam os grupos separados. A pilha começa com
o pixel inicial. Cada vez que retirar um pixel, some um à área e
atualize as coordenadas que delimitam a caixa. Para calcular o
centro, divida a soma de X e a soma de Y pela quantidade de pixels.

detectar_celulas ignora regiões que tocam a borda. Multiplica a área
medida pela razão das larguras vezes a razão das alturas, estimando
pixels² no original. Se passar pelos limites, guarda centro e caixa.
O centro está na escala original. A caixa está na escala da prévia.
Incorporar sugestões aplica a distância mínima e transfere os pontos
aceitos para marcacoes. Sugestões pendentes ficam fora dos resultados
e do PNG exportado. Células unidas por pixels ativos podem virar uma
só região. Use a revisão visual para ajustar a contagem.

8.2. Do clique em Salvar até o arquivo em disco

salvar_analise monta um dicionário com o ID, os textos, os totais,
as dimensões, a data e os pontos. A cópia da imagem recebe o mesmo
identificador. O JSON é escrito com um nome temporário. replace
define o nome definitivo depois de fechar a escrita. O histórico
busca apenas .json. Na leitura, carregar_analise abre pelo ID.
O método de consulta recria a prévia a partir da imagem arquivada e
dos pontos. Se a imagem não estiver disponível, os dados do registro
e as coordenadas continuam disponíveis para consulta.

O PNG usa desenhar_marcadores(resolucao_original=True). Para CSV,
exportar_csv usa CAMPOS_CSV tanto no cabeçalho quanto no laço que
preenche cada linha. TEXTOS_CSV identifica os campos de texto que
passam por texto_csv. Um apóstrofo inicialmente acrescentado a
valores como =1+2 ajuda a planilha a tratá-los como texto. O valor
original fica no JSON. As coordenadas viram uma string JSON em
uma célula da planilha, por exemplo [[10, 20], [30, 50]].


9. ESTILO DO NAVEGADOR E CONFIGURAÇÕES

HTML estrutura o cabeçalho e os indicadores. <header> identifica o
cabeçalho. <div> contém elementos. <h1> e <p> representam o título
e o parágrafo. <span> agrupa texto curto e <strong> destaca o
número. </div>, por exemplo, fecha o elemento. class="indicador"
permite aplicar estilo. aria-live="polite" auxilia leitores de
tela a anunciar mudanças e aria-hidden="true" omite o ícone
decorativo nessa leitura. Markdown usa ## para títulos.

Em CSS, um seletor escolhe os elementos. .painel é uma classe e
#visualizacao é um identificador. ".indicador strong" escolhe
o strong dentro do indicador. Gradio associa os nomes por elem_id
e elem_classes. Entre { e }, escreva pares como "color: #fff;".
Em CSS, #46f6ff é uma cor hexadecimal. No código Python, # dentro
dessa string faz parte do texto e do seletor ou da cor.

• color e background definem a cor do texto e o fundo. background
  aceita linear-gradient para misturar cores ao longo de um ângulo.
  var(--nome) busca um valor reutilizável fornecido pelo tema.
• margin é a distância externa, padding é a interna. gap cria
  espaço entre elementos. border adiciona uma borda e border-radius
  arredonda os cantos. height e min-height ajustam a altura.
• display: flex ou grid organiza elementos. align-items, flex-wrap,
  flex e place-items ajudam no alinhamento e na quebra em telas
  estreitas. Em propriedades de tamanho, px indica pixels, vh
  usa uma fração da altura da janela e clamp limita entre três valores.
• font-size, line-height e font-weight ajustam o texto.
  font-variant-numeric: tabular-nums dá a mesma largura aos algarismos
  nas fontes compatíveis. cursor: crosshair indica a área de marcação.
• @media (max-width: 640px) aplica as regras internas a janelas
  estreitas. Reinicie o servidor após alterar app.py para rever
  o resultado.

requirements.txt tem uma linha por pacote. == fixa a versão usada
no computador. pip install -r requirements.txt lê todas as linhas
e instala dependências. O Android tem sua própria lista no pip do
build.gradle. Ele empacota Pillow e o núcleo Python com o aplicativo.

10.1. Ler Java com o que você aprendeu em Python

• package e import identificam o pacote do arquivo e os nomes
  usados. Os tipos aparecem na declaração, como int, float,
  boolean, String, Bitmap e void. void indica método sem retorno.
  new cria objetos e arrays. null representa ausência de referência.
• Os blocos ficam entre { e }. Instruções geralmente terminam
  em ponto e vírgula. if, else, for, while e return exercem
  papéis parecidos com suas versões em Python. Em for (int i = 0;
  i < abas.length; i++), declare i, teste seu limite e aumente i
  a cada repetição. Arrays usam Tipo[] e índice começando em 0.
• = atribui. ++ soma 1. &&, || e ! correspondem a and, or e not.
  A forma condicao ? valorA : valorB escolhe um resultado. Em
  textos, use .equals(...) para comparar o conteúdo. O operador
  + também junta texto. O cast (int) converte uma posição para
  inteiro. Literais 2f e 0xff112540 representam respectivamente
  um float e um inteiro hexadecimal, que aqui codifica a cor ARGB.
• public, private e protected controlam o acesso. static liga um
  membro à classe. final impede reatribuir uma variável ou
  estender uma classe declarada final. Uma referência final
  ainda pode apontar para um objeto editável.
• extends declara herança. TelaCellCount herda de Activity e
  ImagemAnalisavel herda de View. @Override indica que um
  método substitui uma implementação herdada. super.onCreate
  chama a versão de Activity. this se refere à tela ou vista
  atual. interface Toque define o contrato que recebe os dois
  inteiros ao tocar na imagem.
• () -> editar("desfazer") cria uma função curta sem argumentos
  que será executada ao clicar. Em this::escolherImagem, ::
  referencia um método já definido. Os objetos anônimos dos
  detectores de gesto especificam dentro de { } as ações de
  cada evento.
• Object... argumentos aceita uma quantidade variável de
  argumentos. Callable<Runnable> descreve uma tarefa que devolve
  uma ação para executar. O ExecutorService processa uma ação
  por vez fora da interface. runOnUiThread devolve a atualização
  para a tela. A variável ocupado evita que o usuário inicie
  outra edição enquanto o resultado anterior está sendo calculado.
• try, catch, throw, throws e finally lidam com erros. Em
  try (InputStream origem = ...), Java fecha a leitura no final
  do bloco. finally executa mesmo quando a exportação falhar.
  lerInteiro usa Integer.parseInt e trata NumberFormatException.

12. EXERCÍCIO PRÁTICO COM O NÚCLEO DO CELLCOUNT

Crie um arquivo de exercício, por exemplo estudo_cellcount.py, na
raiz do projeto. Copie o programa abaixo. Ele gera uma imagem com
dois quadrados escuros e usa os mesmos métodos da interface para
detectá-los. Use nomes de arquivos novos para a imagem e a saída.

    from PIL import Image, ImageDraw
    from contador import ContadorCelulas

    foto = Image.new("RGB", (80, 60), "white")
    desenho = ImageDraw.Draw(foto)
    desenho.rectangle((8, 8, 16, 16), fill="black")
    desenho.rectangle((40, 30, 49, 39), fill="black")
    foto.save("entrada_estudo_cellcount.png")

    contador = ContadorCelulas("entrada_estudo_cellcount.png")
    print(contador.obter_total())
    print(contador.detectar_celulas(128, False, 20, 0))
    print(contador.incorporar_sugestoes(8))
    print(contador.obter_total())
    contador.desenhar_marcadores(resolucao_original=True).save(
        "saida_estudo_cellcount.png"
    )

Execute o exercício na raiz do projeto.

    .\.venv313\Scripts\python.exe estudo_cellcount.py

A saída esperada é 0, 2, 2 e 2, cada número em sua linha. A contagem
começa vazia. O segundo número indica as regiões sugeridas. O terceiro
indica quantas entraram na lista. O último confirma o total. Abra o PNG
de saída para ver os dois marcadores. Troque a área mínima de 20 para
90 e rode novamente. O quadrado de 9 × 9 fica abaixo do limite, e o de
10 × 10 passa. Essa mudança permite observar o filtro com números
cuja área você consegue calcular à mão.
