CELLCOUNT — 02 | PROGRAMAÇÃO ORIENTADA A OBJETOS
==============================================

1. Por que organizar em objetos

Programação orientada a objetos (POO) agrupa dados e operações sobre
eles. Uma classe descreve esse agrupamento por meio de class; um
objeto, ou instância, é criado a partir dela e guarda seus próprios
valores. No projeto, ContadorCelulas reúne as coordenadas de uma
imagem e operações como desfazer e redesenhar.

    from contador import ContadorCelulas

    contador_a = ContadorCelulas("imagem_a.png")
    contador_b = ContadorCelulas("imagem_b.png")
    contador_a.adicionar_celula(10, 20, 0)
    print(contador_a.obter_total(), contador_b.obter_total())

Use arquivos PNG válidos com pelo menos 11 × 21 pixels para rodar o
exemplo. A chamada da classe cria uma instância a cada vez. A saída
é 1 0 porque cada instância recebe sua lista de marcações.

2. O método __init__

Este recorte vem de ContadorCelulas em contador.py.

    def __init__(self, caminho):
        self.caminho = Path(caminho)
        self.nome = self.caminho.name
        self.extensao = self.caminho.suffix.lower()
        self.marcacoes = []

__init__ é chamado automaticamente após a criação da instância e
define seus dados iniciais. Ao escrever ContadorCelulas("imagem_a.png"),
o Python passa o novo objeto em self e a string em caminho. Path
cria um objeto para trabalhar com o caminho. Depois da parte mostrada,
__init__ abre a imagem, guarda sua resolução e cria a prévia. Se a
imagem não puder ser aberta, a exceção interrompe a inicialização e
carregar_imagem em app.py exibe uma mensagem. __init__ termina sem
return explícito porque seu trabalho é preencher o objeto.

3. O parâmetro self

self é a referência à instância que recebeu a chamada. O ponto em
self.marcacoes acessa o atributo dessa instância. Se o método usasse
apenas marcacoes = [], a variável seria local e sumiria ao sair do
método. A comparação a seguir mostra como a chamada é resolvida.

    contador_a.obter_total()
    ContadorCelulas.obter_total(contador_a)

As duas chamadas obtêm o mesmo resultado. A primeira é o jeito usado
no projeto. Python fornece contador_a como self automaticamente.
Você escreve self na definição do método e fornece somente os outros
argumentos na chamada pelo objeto.

4. Atributos e métodos

Um atributo é um valor acessível com objeto.nome. Um método é uma
função definida dentro da classe e chamada com objeto.metodo(...).

    print(contador_a.nome)
    print(contador_a.largura, contador_a.altura)
    print(contador_a.marcacoes)
    contador_a.desfazer_marcacao()
    print(contador_a.obter_total())

Os prints leem atributos, enquanto desfazer_marcacao altera a lista.
LIMITE_PREVIA e COR_MARCADOR são atributos da classe, declarados
fora de __init__. Todas as instâncias consultam esses valores por
meio de self. marcacoes é atributo da instância e é criado dentro de
__init__, para que cada análise receba uma lista nova.

5. Como as três classes colaboram

AplicacaoCellCount (app.py) cria um GerenciadorAnalises e o guarda em
self.analises. construir_interface organiza os componentes e devolve
gr.Blocks, guardado em self.interface. Quando um arquivo é carregado,
carregar_imagem cria um ContadorCelulas. O gr.State do navegador guarda
aquele objeto e o fornece aos eventos de clique, desfazer, limpar,
salvar e exportar. Um novo carregamento cria um novo objeto.

GerenciadorAnalises (analises.py) recebe um ContadorCelulas ao salvar.
Lê atributos como nome e largura, chama obter_total() e copia a lista
para o registro. Depois de anotada outra célula na aba Contagem, o
registro salvo conserva a lista anterior. Para reabrir, a aplicação
lê o dicionário e cria um contador separado com a imagem arquivada.
Por fim, preenche as marcações desse objeto com os pontos do JSON e
alimenta apenas a aba Histórico.

Esta relação é de composição. A aplicação usa objetos das outras
classes e delega o trabalho correspondente. Para trocar a cor do
marcador, procure ContadorCelulas. Para alterar as colunas do CSV,
procure GerenciadorAnalises. Para mudar um botão, procure
AplicacaoCellCount.
