CELLCOUNT — 06 | COMO EXECUTAR
==============================

Este guia cobre a versão para computador e Colab. Para instalar o
CellCount no Android, consulte 08_android.txt.

1. Preparar o Python no Windows

Use Python 3.13 no Windows. Neste projeto, o ambiente .venv313 já foi
preparado com essa versão. Em outra máquina, use o instalador oficial
do Python 3.13 e habilite a opção
que adiciona Python ao PATH, se ela aparecer. Feche e abra o terminal
depois da instalação e execute `python --version`.
https://www.python.org/downloads/

No VS Code, use Arquivo > Abrir Pasta e selecione a pasta que contém
app.py, contador.py, analises.py e requirements.txt. Instale a extensão
Python da Microsoft no VS Code se quiser selecionar o interpretador e
acompanhar o código com o depurador.

2. Instalar dependências e iniciar o servidor

Abra Terminal > Novo Terminal no VS Code. Na pasta do projeto, confira
se o ambiente .venv313 está disponível e execute o aplicativo com ele.
Os comandos funcionam no PowerShell e no CMD.

    dir requirements.txt
    .\.venv313\Scripts\python.exe --version
    .\.venv313\Scripts\python.exe app.py

Se estiver preparando o projeto em outra máquina, crie o ambiente com
o Python 3.13 instalado e depois instale as dependências.

    py -3.13 -m venv .venv313
    .\.venv313\Scripts\python.exe -m pip install -r requirements.txt

O comando dir confirma que requirements.txt está na pasta atual. Se o
arquivo não aparecer, siga a seção 6.1. Ao usar o caminho do Python do
ambiente, você dispensa a ativação pelo PowerShell. No VS Code, a ação
Python: Select Interpreter permite selecionar .venv313\Scripts\python.exe.
Se você já tinha selecionado outro ambiente neste projeto, use essa ação
para trocar para .venv313.

Deixe o terminal aberto. Acesse o endereço local mostrado pelo Gradio
no navegador, por exemplo http://127.0.0.1:7860. Se a porta mudar, use a
que aparece no seu terminal. Pressione Ctrl+C no terminal para encerrar.

3. Usar a aba Contagem

1) Escolha ou arraste uma imagem PNG, JPG, JPEG, TIF ou TIFF compatível
   para o campo de carregamento. Confira o nome e a resolução na tela.
   TIFFs com várias páginas usam a primeira. Para trocar de imagem,
   remova a atual pelo × no campo de carregamento e escolha outra.
2) Clique sobre cada célula. O círculo aparece e o total sobe. Use o
   ícone de tela cheia no canto da imagem se precisar de mais espaço.
3) Use Desfazer para remover o último ponto ou Limpar marcações para
   reiniciar a contagem sem trocar a imagem.
4) Ajuste Distância mínima (px) conforme a resolução e o espaçamento
   da amostra. O padrão é 8 px originais. Zero permite pontos próximos
   e admite inclusive repetição exata.
5) Preencha Nome da amostra. Acrescente Observações se necessário e
   clique em Salvar análise. Cada salvamento cria um registro novo.
   Salve a contagem antes de trocar a imagem ou fechar a página.

Para usar a contagem assistida, abra Detecção assistida abaixo da
imagem. Escolha Escuras ou Claras conforme o contraste da amostra e
clique em Detectar possíveis células. Se detectar poucas células
escuras, experimente aumentar o limiar. Para células claras, tente
diminuí-lo. Aumente a área mínima para filtrar pontos pequenos e use
a área máxima para limitar regiões grandes. As áreas são estimadas
em pixels² da imagem original. Área máxima 0 deixa o limite aberto.

Cada caixa laranja é uma sugestão. Clique dentro de uma caixa para
rejeitá-la, fora das caixas para marcar manualmente, ou use Descartar
todas para reiniciar a revisão. Incorpore as caixas restantes com
Incorporar sugestões. Só os pontos confirmados entram no total e nas
exportações. Ajuste os controles e execute novamente se quiser gerar
outras sugestões. Confira células juntas, com baixo contraste ou
cortadas pela borda e complete a contagem manualmente.

4. Histórico, Resultados e exportação

Em Histórico, clique numa linha para consultar identificação, amostra,
data, total e observações. Abra Coordenadas em pixels (X, Y) para ver
os pares. A prévia reaparece com os pontos se a imagem arquivada estiver
disponível. Resultados mostra três indicadores calculados a partir da
análise ativa e dos registros gravados.

Para obter o PNG da análise atual, clique em Exportar imagem (PNG) na
aba Contagem e depois em Baixar PNG para obter imagem-anotada.png.
O PNG contém os marcadores na resolução original. Para obter a planilha
de análises salvas, use Exportar resultados (CSV) em Histórico e clique
em Baixar CSV para obter resultados-cellcount.csv. Ao importar numa planilha, escolha UTF-8 e
vírgula como separador se as colunas aparecerem juntas. Cada campo
marcacoes contém as coordenadas como um array JSON.

O programa cria dados/ e dados/imagens/ junto de app.py. Cada análise
tem seu JSON em dados/ e sua imagem original em dados/imagens/. Ao fazer
uma cópia de segurança, preserve a estrutura da pasta dados inteira.
O CSV reúne os resultados tabulares e a relação entre os arquivos fica
no JSON. A contagem atual é mantida em memória até ser salva.

5. Rodar no Google Colab

Abra um notebook Colab com ambiente Python. Coloque app.py, contador.py,
analises.py e requirements.txt na mesma pasta da sessão, por exemplo
/content/CellCount. Abra uma célula e ajuste o caminho conforme a pasta.

    %cd /content/CellCount
    %pip install -r requirements.txt

Em outra célula, inicialize o aplicativo. Verifique se a instalação
terminou primeiro. Se o Colab pedir reinício do ambiente, reinicie e
execute o %cd novamente antes de importar.

    from app import AplicacaoCellCount
    AplicacaoCellCount().executar()

Abra a interface exibida pelo Gradio enquanto a célula estiver em
execução. No Colab, o Gradio cria um endereço temporário para conectar
o navegador ao servidor do notebook. Quem tiver o endereço poderá
acessar a interface durante essa execução. Use imagens de estudo
adequadas para esse ambiente ou execute localmente para manter o acesso
na sua máquina. As pastas em /content são temporárias. Preserve dados/
antes de encerrar a sessão se for necessário continuar em outro dia.
https://gradio.app/docs/gradio/blocks

6. Resolver erros comuns

6.1. Pip não encontrou o arquivo requirements.txt

Se aparecer `ERROR: Could not open requirements file: [Errno 2]`,
verifique a pasta que aparece antes do sinal > no Prompt de Comando.
Por exemplo, `C:\Users\Gabriel Melo>` indica que o terminal está na
pasta pessoal. Como `-r requirements.txt` usa um caminho relativo,
o pip procura o arquivo nessa pasta. O aviso `[notice]` informa apenas
que existe uma versão mais recente do pip. A instalação pode continuar
com a versão atual assim que o terminal estiver na pasta do projeto.

No Prompt de Comando (CMD), entre na pasta do CellCount e confira se o
arquivo aparece. Use o caminho da pasta em que você guardou o projeto
caso ela esteja em outro local.

    cd /d "%USERPROFILE%\Documents\appCelulas"
    dir requirements.txt

`%USERPROFILE%` aponta para a sua pasta pessoal. As aspas acomodam
espaços no caminho, e `/d` permite trocar de unidade, se necessário.
Se o comando dir ainda não listar requirements.txt, localize a pasta
que contém app.py e requirements.txt pelo Explorador de Arquivos e
repita o cd com o caminho dela.

Depois que o arquivo aparecer, use o ambiente .venv313 do projeto.
Execute os comandos a seguir no CMD dentro da pasta do projeto.

    .\.venv313\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv313\Scripts\python.exe app.py

Se .venv313 não estiver disponível, siga os passos de criação da seção 2.

6.2. Outros erros comuns

• Python 3.13 não encontrado. Se .venv313 já estiver pronto, use o caminho
  explícito da seção 2. Em outra máquina, instale Python 3.13 e reabra o terminal.
• Pip informa `No matching distribution found for pyyaml`. Confira a
  versão com `.\.venv313\Scripts\python.exe --version` e use esse ambiente
  com Python 3.13. A instalação do PyYAML falhou no Python 3.15 neste Windows.
• ModuleNotFoundError: gradio ou PIL. Instale requirements.txt com o mesmo
  interpretador usado para rodar app.py. PIL é importado pelo código e
  a dependência que fornece esse módulo se chama Pillow.
• Imagem recusada. Abra o arquivo em um visualizador e confira se formato
  e extensão combinam. Caso seu TIFF use um formato incompatível, exporte
  uma cópia PNG no seu visualizador e analise essa cópia.
• O navegador perdeu a conexão. Confira se o processo Python continua
  ativo e copie a URL mais recente do terminal ou do notebook.
• Detecção assistida não aparece. Pode haver uma versão anterior do
  CellCount aberta em outra porta. Confira a URL do terminal que executa
  a versão atual e abra esse endereço na aba Contagem. Salve a análise
  em andamento antes de encerrar uma sessão anterior.
• A imagem de uma análise antiga sumiu. Verifique a pasta dados/imagens.
  O JSON guarda os pontos e os demais dados, que continuam consultáveis.
• O link do Colab não abriu. Confirme que a célula continua ativa e use o
  endereço anunciado por essa execução. Se o ambiente bloquear o túnel do
  Gradio, execute a versão local usando os passos das seções 1 e 2.
